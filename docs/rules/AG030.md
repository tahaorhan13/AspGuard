# AG030: Member has no XML documentation comment

| | |
|---|---|
| Category | Documentation |
| Default severity | Info |
| Code fix | Yes: generates `/// <summary>` from the member name |

## Cause

A method or constructor has no `///` (or `/** */`) documentation comment.

Not reported: overrides (they inherit the base documentation), explicit interface implementations, partial methods,
static constructors, local functions, lambdas and generated code.

## Code fix

**Add XML documentation comment** inserts a summary derived from the name. The text comes from rules (word splitting, a
verb table and a noun/adjective dictionary), not from an AI model: it is instant, offline, free and always the same.

```csharp
public void AddPerson(Person person) { }      // AG030
```

becomes

```csharp
/// <summary>
/// Kişi ekler.
/// </summary>
public void AddPerson(Person person) { }
```

How names are read:

| Pattern | `tr` | `en` |
|---|---|---|
| Verb + object: `DeleteClaim` | Tazminat siler. | Deletes the claim. |
| Plural object: `GetUsers` | Kullanıcıları getirir. | Gets the users. |
| Noun compound: `GetOrderItems` | Sipariş öğelerini getirir. | Gets the order items. |
| `By`/`For`/`From`/`To`/`With`/`In`/`Of`: `GetUserById`, `AddItemToCart` | Kimliğe göre kullanıcı getirir. / Sepete öğe ekler. | Gets the user by id. / Adds the item to cart. |
| Two verbs: `AddOrUpdateUser` | Kullanıcı ekler veya günceller. | Adds or updates the user. |
| `Is`/`Has`/`Can`/`Should` | Aktif olup olmadığını belirtir. | Determines whether it is active. |
| `Try` + verb: `TryParseDate` | Tarih ayrıştırmayı dener. | Tries to parse the date. |
| `On` + event: `OnClick` | Click olayını işler. | Handles the click event. |
| Constructor | `<see cref="T"/>` sınıfının yeni bir örneğini oluşturur. | Initializes a new instance of the `<see cref="T"/>` class. |
| Unknown first word: `Frobnicate` | Frobnicate işlemini gerçekleştirir. | Performs the frobnicate operation. |

A trailing `Async` is ignored. Words outside the dictionary are kept in English.

## Configuration

```ini
[*.cs]
aspguard.doc_language = tr              # default; or en
dotnet_diagnostic.AG030.severity = none # turn the rule off
```

Document a whole project or solution:

```bash
dotnet format analyzers --diagnostics AG030 --severity info
```

## When to suppress

Turn the rule off for test projects or generated-looking code where summaries add nothing. The generated text is a
starting point: replace it when the name does not tell the whole story.
