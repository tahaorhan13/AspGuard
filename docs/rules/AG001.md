# AG001: Database query executed inside a loop

| | |
|---|---|
| Category | Performance |
| Default severity | Warning |
| Code fix | Yes, for `FirstOrDefault(e => e.Prop == loopVar)` in a `foreach` (see below) |

## Cause

An EF Core query is executed in the body of a `foreach`, `for`, `while` or `do` loop. This is the classic
**N+1** problem: one query to get the list, then one more query for every element.

Detected executions (verified semantically, never by name alone):

- `ToList`, `ToArray`, `ToDictionary`, `First*`, `Single*`, `Last*`, `Count`, `LongCount`, `Any`, `All`, `Sum`, `Min`,
  `Max`, `Average`, `Contains`, `ElementAt*`, `Load` and their `Async` variants on an `IQueryable` that traces back to a
  `DbSet<T>`;
- `ExecuteDelete` / `ExecuteUpdate` (and `Async`);
- `DbSet<T>.Find` / `FindAsync` and `DbContext.Find` / `FindAsync`.

Not reported: the collection expression of a `foreach` and the initializer of a `for` (they run once), queries on
in-memory collections (LINQ to Objects), results that were already materialized, and queries inside local functions
or lambdas that are not an in-memory `Select`/`Where`/`ForEach` (see [AG002](AG002.md)).

## Example

```csharp
foreach (var id in orderIds)
{
    var order = await db.Orders.FirstOrDefaultAsync(o => o.Id == id);   // AG001
}
```

## How to fix

Load everything in one query before the loop:

```csharp
var orders = (await db.Orders.Where(o => orderIds.Contains(o.Id)).ToListAsync())
    .ToLookup(o => o.Id);

foreach (var id in orderIds)
{
    var order = orders[id].FirstOrDefault();
}
```

Use `Include` when the loop walks a navigation property.

### Code fix

For `foreach` loops that call `FirstOrDefault`, `SingleOrDefault` (or their async versions) with a single equality
predicate on the loop variable, the code fix inserts the `Contains` query + `ToLookup` before the loop and replaces the
call. Other shapes (including `Find`, because the key property cannot be known from syntax) get no fix.

## Entity Framework 6

The rule recognizes EF6 (`System.Data.Entity`) the same way: `DbSet<T>` and `IDbSet<T>` sets, `QueryableExtensions`
(`ToListAsync`, `FirstOrDefaultAsync`, `Load`, ...) and `DbSet.Find`/`FindAsync`. The code fix works on EF6 code too.

## When to suppress

If the loop is bounded and tiny, or deliberately sequential, use
`#pragma warning disable AG001` locally or `dotnet_diagnostic.AG001.severity = none` in `.editorconfig`.

To limit the rule to selected code, set `aspguard.scope = attributed_only` in `.editorconfig` and mark classes or
methods with `[GuardQueries]` (see the README).
