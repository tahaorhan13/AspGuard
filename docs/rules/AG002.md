# AG002: Database query executed inside an in-memory Select/ForEach lambda

| | |
|---|---|
| Category | Performance |
| Default severity | Warning |
| Code fix | No |

## Cause

An EF Core query is executed inside the lambda of `Enumerable.Select`, `SelectMany`, `Where`, `List<T>.ForEach` or
`Array.ForEach`. These run the lambda once per element of an in-memory collection, so the query runs N times, exactly
like a loop (see [AG001](AG001.md)).

`IQueryable` operators such as `db.Orders.Select(o => db.Items.Count(...))` are **not** reported: their lambdas are
expression trees that EF translates into a single SQL statement.

## Example

```csharp
var orders = ids.Select(id => db.Orders.Find(id)).ToList();          // AG002
```

## How to fix

```csharp
var orders = await db.Orders.Where(o => ids.Contains(o.Id)).ToListAsync();
```

## When to suppress

Same options as [AG001](AG001.md).
